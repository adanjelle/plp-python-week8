
# PLP Python Week 8 — Python Toolkit

## Project Description

Python Toolkit is a menu-driven Python program containing three useful tools. It demonstrates functions, loops, lists, conditional statements, exception handling and user input.

## Tools Included

1. **Simple Calculator** — Performs addition, subtraction, multiplication and division.
2. **To-Do List Manager** — Allows users to add, view and remove tasks.
3. **Number Guessing Game** — Generates a random number and challenges users to guess it.

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 toolkit.py
```

## Project Files

- `toolkit.py` — Main Python program.
- `toolkit_plan.txt` — Initial project plan.
- `screenshots/` — Screenshots showing the tools in action.

## Reflection

The most challenging part of this project was connecting all three tools to one main menu. The To-Do List Manager required careful handling of list operations and user input. The longest bug to troubleshoot was ensuring that invalid inputs did not crash the program. I learned how to use functions to organize code and make programs easier to understand. I also improved my understanding of loops, lists and conditional statements. If I had one more week, I would add a feature that saves tasks permanently so they remain available after restarting the program. Overall, this project helped me become more confident in building interactive Python applications.
